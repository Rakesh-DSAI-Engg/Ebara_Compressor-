# Ebara_Compressor-

## Industrial Compressor – Data Analytics and Exploratory Data Science

### Project Overview

This project focuses on analysing industrial compressor operational data using Data Science techniques.

The objective is to understand compressor operating behaviour through sensor measurements, identify data quality issues, explore operational patterns and establish a foundation for further machine learning applications in industrial equipment analytics.

### My Contributions

- **Dataset Understanding:** Examining the structure and characteristics of industrial compressor operational data.
- **Data Preprocessing:** Cleaning raw datasets, handling metadata and preparing timestamp-based records.
- **Sensor Mapping:** Organizing sensor tag names, engineering descriptions and measurement units.
- **Data Validation:** Checking missing values, timestamp consistency and data availability.
- **Exploratory Data Analysis:** Analysing sensor distributions, trends and relationships across operational parameters.
- **Time-Series Analysis:** Understanding hourly operational measurements and identifying data gaps.
- **Feature Preparation:** Preparing structured sensor data for further statistical analysis and machine learning applications.

### Technical Areas

To develop a structured analytical foundation for understanding industrial compressor performance and supporting future data-driven operational intelligence applications.
